# Delta Battle (Forge 1.20.1)

Битва в стиле Deltarune с пати и Фроггитом из Undertale.

## Сборка
1. Файлы проекта (`build.gradle`, `settings.gradle`, `src/`) должны лежать В КОРНЕ репозитория. JDK 17, Gradle 8.1.1: `gradle build` -> `build/libs/deltabattle-1.0.0.jar` (клади в `mods/`). Для запуска из IDE: `./gradlew runClient`.
Мод нужен и на сервере, и на клиенте.

## Как играть
- `/dparty invite <ник>` - позвать игрока в пати (до 4). Ему придёт кликабельное [ПРИНЯТЬ] (или `/dparty accept`).
  Также `/dparty decline | leave | list`.
- Фроггит: яйцо призыва (креатив) или естественный спавн в болотах. Подойти / ПКМ / ударить - начнётся бой
  для всей пати лидера (кто в радиусе 32 блоков).
- Управление: стрелки/WASD - выбор и движение сердца, Z/Enter - выбор, X - назад (в атаке - медленнее).
- Команды: БИТЬ (шкала тайминга), ДЕЙСТВИЕ (Осмотреть / Похвалить / Пригрозить / Лечение за 32 TP),
  ПРЕДМЕТ (Монстр-конфета из инвентаря, +10 HP), ПОЩАДА (работает после Похвалы/Угрозы), ЗАЩИТА (+TP, урон x0.5).
- Каждый игрок управляет своим сердцем в общей коробке. Погибшие возрождаются с 1/8 HP, если пати проиграла.

## Фроггит (по Undertale)
HP 30, ATK 4, DEF 5. Атаки: 5 мух сверху - зависают и летят в душу; лягушка из правого нижнего угла прыгает
со случайной силой на другую сторону; редкий вариант (8%) - мухи плавно падают вниз. Реплики и тексты оригинала.

## Оптимизация
- Пули не передаются по сети: позиции - чистая функция (тип, seed, время), считаются на сервере и клиентах.
- Сеть: 1 пакет души ~5 байт/тик на игрока, позиции союзников 10 Гц, AIM мух - раз на муху.
- Рендер: интерполяция по реальному времени (плавно на любом FPS), scissor вместо клиппинга, нулевые аллокации
  в цикле пуль, сущность - один билборд-квад.
